# i3wm-config

A collection of scripts and configuration files to set up a polished, stable, and reliable i3wm environment on Arch Linux.

## What this project includes

- Setup scripts to get a clean i3wm environment up and running quickly
- Custom scripts to enhance and personalise the i3wm workflow
- Configuration aimed at being practical and comfortable for daily use

## Platform

This project targets **Arch Linux** specifically. It may work on other distributions with some tinkering to account for differences in package names and system paths.
